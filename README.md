## Giới thiệu

Chào mừng đến với `hoc` — không gian lưu trữ hành trình học lập trình của Hải. Repository tập hợp các bài luyện tập C++, Python, cấu trúc dữ liệu và thuật toán theo từng giai đoạn học tập.

Mục tiêu của repository là giúp Hải và người đọc:

- Tìm nhanh bài tập theo ngôn ngữ, thư mục và chủ đề.
- Quay lại một bài cũ mà không cần đoán tên file.
- Ôn tập theo nhóm kiến thức thay vì chỉ theo ngày nộp.
- Biên dịch và chạy nguồn một cách nhất quán.

Tài liệu trong repository mô tả đúng các file hiện có. Repository không suy diễn trạng thái AC, thành tích hoặc tiến độ học tập khi chưa có bằng chứng.

## Biên dịch và chạy

### C++

Yêu cầu máy có trình biên dịch C++ hỗ trợ chuẩn C++17. Ví dụ với `g++`:

```powershell
g++ -std=gnu++17 -O2 .\hoc_C++\CANBANG.cpp -o .\hoc_C++\CANBANG.exe
.\hoc_C++\CANBANG.exe
```

Với các bài trong `Bài_GV_Tin\Nộp`, nhiều file sử dụng `freopen` để đọc `.INP` và ghi `.OUT`. Khi chạy nhóm này, hãy đặt file input/output tương ứng trong cùng thư mục với source hoặc chạy chương trình từ thư mục đó.

### Python

```powershell
python .\hoc_python\python_day1.py
python .\hoc_python\python_day2.py
```

Các chương trình Python đọc dữ liệu từ stdin theo mã nguồn hiện có.

## Ghi chú học tập

- Ưu tiên đọc [INDEX.md](INDEX.md) để chọn bài theo chủ đề trước khi mở từng file.
- Khi ôn một chủ đề, hãy so sánh cách dùng mảng, `map`, prefix và xâu trong nhiều bài.
- Với bài dùng file `.INP/.OUT`, kiểm tra thư mục làm việc hiện tại trước khi chạy.
- Với số lớn hoặc số vượt kiểu nguyên, chú ý các bài biểu diễn số bằng xâu.
- Không dùng file `.exe` hoặc `.OUT` làm bằng chứng trạng thái AC; tài liệu chỉ ghi nhận nguồn hiện có.
- Giữ nguyên tên file và cấu trúc thư mục để các liên kết trong repository ổn định.
