## Quy ước chạy bài

Nhiều source trong nhóm này dùng `freopen` với file `.INP` và `.OUT`. Khi chạy một bài, hãy kiểm tra tên file input/output trong source và đặt chương trình ở thư mục có các file tương ứng.

Các file `.exe`, `.OUT`, `.doc` và `.docx` được giữ nguyên theo repository gốc. README này không suy diễn trạng thái AC hoặc tiến độ học tập.
