## Lưu ý kỹ thuật khi chạy bài

1. **Đọc ghi tệp (`freopen`)**:
   - Phần lớn các bài trong các đợt nộp đều sử dụng tệp nhập xuất định dạng `.INP` và `.OUT` (ví dụ `freopen("CANBANG.INP", "r", stdin); freopen("CANBANG.OUT", "w", stdout);`).
   - Khi chạy thử nghiệm trên máy, cần tạo file `.INP` có tên tương ứng trong cùng thư mục chạy chương trình.
2. **File thực thi (`.exe`) và kết quả (`.OUT`)**:
   - Các file nhị phân và file mẫu kết quả trong thư mục được lưu giữ nguyên trạng phục vụ lưu trữ học tập cá nhân.
3. **Mục lục đầy đủ từng bài**:
   - Xem bảng mã nguồn, phân tích thuật toán và liên kết từng file tại: [INDEX.md](../../INDEX.md)
